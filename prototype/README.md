# Clickable prototype

`index.html` runs the real Hub screens against made-up data, so people can try the app before anyone installs it.

**Open it:** double-click `index.html`, or open it from GitHub Pages. No server or sign-in is needed.

## What to try

Press **What to try** at the top right of the page. Each line is something a Business Analyst expects, and **Show me** takes you to the screen that delivers it.

| What a BA expects | Where it happens | Try this |
|---|---|---|
| Add a requirement in about three minutes | Capture | Answer the questions one at a time and save on the last step |
| Find any requirement quickly | Register | Type in the search box, then narrow by process, priority or person |
| See the big picture at a glance | Register | Click a slice, bar or point in a chart and the page filters to it |
| See who changed what, and when | Audit log (Owner) | Filter by action, source or date |
| Control who can view or edit | Access (Owner) | Approve the pending request, add a person, change a role |
| Check what each role sees | The **View as** buttons | Switch between Owner, Editor, Viewer and New user |

## What is different from the real app

- The data is invented and lives only in your browser tab. Reload to reset it.
- There is no Google Sheet behind it. **Open source file** goes to a placeholder.
- No email is sent when you approve access or add someone.
- Everything else, including validation, roles and the filters, uses the same code as the real app.

The prototype includes the Instrument Sans font, so it works offline.
